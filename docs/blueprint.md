# **App Name**: WealthWise Navigator

## Core Features:

- Investment Dashboard: Provide a user-friendly interface for viewing investment options.
- Personalized Recommendations: Generate personalized investment suggestions based on user-provided risk tolerance, goals, and investment horizon, using a risk-assessment tool.
- Market Data Visualization: Display real-time market data (stock prices, index values, etc.) from a public API.
- User Authentication: Implement secure user authentication.
- Learning Resources: Provide educational content about different investment types.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust and stability.
- Background color: Light gray (#EEEEEE) to provide a clean and professional backdrop.
- Accent color: Teal (#009688) for interactive elements and calls to action.
- Font pairing: 'Inter' (sans-serif) for body text, and 'Space Grotesk' (sans-serif) for headlines.
- Use clear, minimalist icons to represent investment categories and actions.
- Design a clean, well-organized layout with clear visual hierarchy.
- Incorporate subtle animations for transitions and data updates.
